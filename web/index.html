Start here

Install and start it.

01

Install the alpha

Run this in a terminal:

npm install -g ownyourbot@alpha

Needs Node.js 18+ and Go 1.24+.

02

Start the daemon

Start the daemon in the background and open its local dashboard.

ownyourbot daemon start
03

Open the dashboard

Use the local dashboard to configure a model, set up an agent, and review its runs.

http://127.0.0.1:8765/dashboard

Current alpha

What you can do.

Configure local models

Save an Ollama or LM Studio endpoint and probe its capabilities before a run.

Set up agents

Edit prompts, choose tools, and set limits. Agents start disabled.

Run and review

Start a run on this computer. Inspect its output, steps, and pending approvals.

Data and network

Runs stay on this computer.

Stored locally

The daemon keeps its configuration and run history on this computer.

Sent to connected services

Model, search, or MCP requests go to the endpoint you configure. Those services receive the data needed to handle each request.

Remote access, phone pairing, and a one-click setup flow are planned. They are not part of the current alpha.
