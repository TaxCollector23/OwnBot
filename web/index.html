Install and start ownbot.

01

Install from source

Run these commands in a terminal:

git clone https://github.com/TaxCollector23/OwnBot.git cd OwnBot npm install -g .

Needs Node.js 18+ and Go 1.24+.

02

Set up your agent

ownbot detects an installed model and creates a text-only agent.

ownbot setup
03

Open the dashboard

Configure in the terminal. Use the dashboard to run tasks, review results, and approve actions.

http://127.0.0.1:8765/dashboard

What you can do.

Configure local models

Save an Ollama or LM Studio endpoint and probe its capabilities before a run.

Set up agents

Configure prompts, tools, and limits in the CLI. Allow tools explicitly.

Run and review

Start a run on this computer. Inspect its output, steps, and pending approvals.

Runs stay on this computer.

Stored locally

The daemon keeps its configuration and run history on this computer.

Sent to connected services

Model, search, or MCP requests go to the endpoint you configure. Those services receive the data needed to handle each request.

Browser pairing works on the same private network. Public internet and cellular access are not supported.
