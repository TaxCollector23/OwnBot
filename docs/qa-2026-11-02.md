# Documentation and virtual sandbox verification

The website is documentation-only. Both `/` and the legacy `/demos` route show the same guides; existing section links remain usable. Videos and animation sources are excluded from Vercel deployment. Historical sources remain in Git.

The refined description is used in the hero, README, package metadata, GitHub Pages introduction, and public repository description. Another-device access remains limited to an SSH tunnel or private-network pairing.

Local browser QA: 260 assertions passed, zero failures. Checks cover both routes at 320, 375, 768, and 1440px, documentation anchors, no video embeds, exact headline, keyboard skip navigation, search and hash/history recovery, no-JavaScript access, command copying, and font fallback. The initial run caught a missing table overflow wrapper and stale demo assertions; both were corrected. The 375px screenshot was inspected.

[Virtual sandbox run](https://github.com/TaxCollector23/OwnBot/actions/runs/41591098077): passed all 60 checks on commit `3bf3c23`. It builds and runs the real CLI and daemon on a disposable Ubuntu VM with deterministic loopback model/MCP fixtures. No model was installed on the user's Mac. This does not establish real inference quality, real account integration, physical-device behavior, or clean service installation.

Fresh [native multi-OS checks](https://github.com/TaxCollector23/OwnBot/actions/runs/41588340895) and the [two-container LAN lab](https://github.com/TaxCollector23/OwnBot/actions/runs/41588340992) also passed on the prior application source, unchanged by this documentation update.
