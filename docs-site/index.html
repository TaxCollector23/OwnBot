Install from source

Development installs require Node.js 18+ and Go 1.24+. The install script builds the CLI and daemon for this machine.

git clone https://github.com/TaxCollector23/OwnBot.git
cd OwnBot
npm install -g . --allow-scripts=ownbot

The npm package is not published yet. After publication, the alpha install will be npm install -g ownbot@alpha.

Choose a local model

Install and start a local runtime first. Setup detects installed models exposed by Ollama, LM Studio, llama.cpp, or vLLM. It probes the model before creating an enabled text-only agent with no tools.

ownbot setup

Setup does not download models or use hosted provider keys. If no model is detected, install a runtime and a model you choose, then run setup again. For a known installed model, use ownbot setup --yes --model MODEL_ID; a config file is available for unattended setup with custom names or prompts.

The local API token

The daemon creates its local API token automatically under ~/.ownbot/api.token. It protects the host's daemon API and is not a model-provider key. The CLI reads it from the host state directory; you do not create or copy it for CLI setup.

Use over SSH

Connect to the host, install ownbot there, then run setup and start the daemon from that SSH session. The host keeps its state and token locally.

ssh user@host
cd OwnBot
ownbot setup
ownbot daemon start

In SSH sessions, the CLI prints a short-lived owner link and an SSH tunnel command instead of opening the host’s browser. Keep the tunnel open and open the printed link on your laptop. The link uses a one-time ticket; it does not contain the API token.

Access from another device

For a device on the same private Wi-Fi or Ethernet, start LAN mode:

ownbot daemon start --lan

Compare the printed HTTPS certificate fingerprint with the host dashboard before trusting the certificate, then run ownbot daemon pair in the host terminal to create a one-use link. LAN access does not provide cellular or public internet access. See the LAN access guide for certificate and revocation steps.
