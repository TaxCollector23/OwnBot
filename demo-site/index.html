Install and start ownbot.

01

Install from source

Run these commands in a terminal:

git clone https://github.com/TaxCollector23/OwnBot.git cd OwnBot npm install -g . --allow-scripts=ownbot

Needs Node.js 18+ and Go 1.24+. Development alpha · release status.

02

Set up your agent

Setup probes a locally served Ollama, LM Studio, llama.cpp, or vLLM model, then creates a text-only agent. It does not download models.

ownbot setup
03

Open the dashboard

Configure in the terminal. Use the dashboard to run tasks, review results, and approve actions.

http://127.0.0.1:8765/dashboard

Run state stays on your computer.

Stored locally

The daemon stores configuration and run records on this computer.

Sent to connected services

Prompts and tool requests go to the model, search provider, or MCP server you configure. Those services process the data needed for each request.

Browser pairing works on the same private network. Public internet and cellular access are not supported.
